# CUA-evaluate-platform

用于评测 **模型 + harness** 组成的 Computer-Use Agent（CUA）在多个公开 benchmark 上的表现。开发环境以 Linux 为主。

当前仓库处于方案阶段，代码实现以根目录 [AGENTS.md](AGENTS.md) 为准。

- [AGENTS.md](AGENTS.md) — 给编程 agent 的开发手册（Cursor VM 阶段 0；真实验证为 Qwen 小模型 + DeepSeek Harness + OSWorld 1 题）
- [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md) — 已确认范围
- [docs/PLAN.md](docs/PLAN.md) — 架构与分期
- [docs/RESOURCES.md](docs/RESOURCES.md) — 计算 / 存储 / 网络
